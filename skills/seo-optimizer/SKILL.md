# SEO Optimizer

## When to use
- "Optimize this page/post for SEO", "why don't we rank for X?", "write a title and meta description".

## Process
1. **Identify the target query and its intent**: informational (learn), commercial (compare), transactional (buy/sign up), navigational. The page type must match the intent.
2. **Study what ranks** (if you can search): what format the top results use (guide, list, tool, product page), what they cover, and what they miss.
3. **Audit the page**:
   - Title tag ≤ 60 chars, primary topic near the start, written for clicks.
   - Meta description ≤ 155 chars, a concrete benefit plus a call to action.
   - One H1; logical H2/H3s that answer the sub-questions people ask.
   - The first paragraph answers the main question directly.
   - Covers related subtopics and terms naturally; no keyword stuffing.
   - Internal links to and from related pages with descriptive anchor text.
   - Images: descriptive file names and alt text, compressed.
   - Clean URL slug; canonical tag; indexable (not blocked by robots or `noindex`).
   - Structured data where relevant (Article, Product, FAQ, HowTo, Organization).
   - Page speed and mobile usability (Core Web Vitals).
4. **Recommend changes**, ordered by impact and effort.

## Rules
- Write for people first; search engines reward pages that satisfy the query.
- Never promise rankings or traffic numbers.
- Do not invent statistics, reviews, or expert quotes to "add authority".
- Prefer updating and consolidating thin or overlapping pages over creating new near-duplicates.

## Output format
```
## Target
Query, intent, page type.

## Quick wins
- Title: "…" (54 chars)
- Meta description: "…" (148 chars)

## Content changes
1. Change — why

## Technical checks
| Check | Status | Fix |
```
