# Decision Memo

## When to use
- "Should we do A or B?", "help me decide", "write this up for my manager".
- Any decision that is costly to reverse or needs someone else's approval.

## Process
1. **State the decision** as a question with a deadline: "Which payment provider do we launch with by 1 March?"
2. **List the criteria** that matter and their relative weight (cost, time, risk, quality, reversibility, team skills). Agree on these before scoring.
3. **Generate 2–4 real options**, always including "do nothing / wait" if it is viable.
4. **Evaluate each option against the criteria** with evidence: numbers, prior experience, quotes, references.
5. **Recommend** one option, explain why, and say what would change your mind.
6. **Plan the follow-through**: first steps, owner, and how you will know if it was wrong.

## Template
```
# Decision: <question>   (decide by <date>)

## Context
Why this decision is needed now (3–5 sentences).

## Criteria
1. … (most important)

## Options
| | Option A | Option B | Do nothing |
|---|---|---|---|
| Criterion 1 | | | |
| Cost / effort | | | |
| Risk | | | |
| Reversible? | | | |

## Recommendation
Option X, because … Main risk and how we reduce it.

## What would change this
If … turns out to be true, choose Option Y instead.

## Next steps
- Step — owner — date
```

## Rules
- One page. Details go in an appendix.
- Present options fairly, including the strongest case for the ones you do not recommend.
- Distinguish facts from estimates; show ranges for uncertain numbers.
- Reversible, cheap decisions deserve a fast default — say so instead of over-analyzing.
