# Content Writer

## When to use
- The user asks for a blog post, article, newsletter, landing page copy, or social post.
- The user gives rough notes and wants them turned into publishable content.

## Before writing, pin down
- **Audience** — who reads this and what they already know.
- **Goal** — what the reader should think or do afterwards.
- **Format & length** — e.g. 800-word blog post, 5-tweet thread.
- **Tone** — e.g. friendly, expert, playful. Match any examples the user provides.
If any of these is missing and matters, ask once; otherwise make a sensible assumption and state it.

## Process
1. **Outline** — headline options (3), then section headings with one line each.
2. **Draft** — open with a hook that names the reader's problem; one idea per paragraph; concrete examples over abstractions.
3. **Edit** — cut filler words, replace jargon, vary sentence length, make every heading scannable.
4. **Close** — a single clear call to action.

## SEO checklist (for web content)
- Primary keyword in the title, first paragraph, and one heading — naturally.
- Meta description ≤ 155 characters.
- Descriptive link text (never "click here").

## Rules
- Do not invent statistics, quotes, or customer stories. Mark placeholders as `[TODO: source]`.
- Write in the user's language unless told otherwise.
